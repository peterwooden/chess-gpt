One move, three representations

Your first win: trace a human chess move all the way to the symbols a language model actually predicts.

Why this comes first

Karpathy's training recipe begins with the data, before neural-network code. In this tournament, representation is also strategy: the model never sees a wooden board or even a move as humans experience it. It sees integer IDs.

Skill for today: distinguish a chess move, its intermediate annotation tokens, and the frozen vocabulary tokens used for training.

The same event at three layers

Suppose a pawn from the e-file captures on f8, promotes to a queen, gives check, and is labelled a blunder:

Human notationexf8=Q+?? → Readable pipeline[??] [+] [x] [=Q] [ef8] → Model vocabulary<blunder> + x =Q ef8

The intermediate brackets make token boundaries visible. Packing then maps [??] to the frozen vocabulary symbol <blunder>, maps every symbol to an integer ID, and stores those IDs. The model predicts one next ID at a time.

Nothing mystical happened. We chose a representation that splits one move into facts: quality, check, capture, promotion, and a core move. That choice determines which patterns are easy or hard for the model to learn.

Prediction before explanation

Do this without looking back

Tokenize Nxf3+? in both the readable pipeline form and packed vocabulary form. Say what each token means.

Reveal immediate feedback

Readable: [?] [+] [x] [Nf3]

Packed: <mistake> + x Nf3

The move is labelled a mistake, gives check, is a capture, and ends with the core knight move to f3. The quality token comes first so the model can condition the coming move on that signal.

Why 50M must include the vocabulary

Every vocabulary token needs a learned embedding row. If model width is 512 and the vocabulary contains 5,273 symbols, the input embedding alone contains:

5,273 × 512 = 2,699,776 learned parameters

That is why our rules draft counts embeddings. Saying “the transformer is 50M” while ignoring several million embedding parameters would let competitors count different things.

Concept check

If we add six new tokens at width 512, how many new embedding parameters appear?

Reveal answer

6 × 512 = 3,072. A vocabulary change can alter both the task and the model size.
