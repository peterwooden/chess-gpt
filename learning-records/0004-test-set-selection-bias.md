# Test-set selection bias understood

The learner predicted that choosing the best of 20 architectures by test score makes the reported score too high relative to fresh unseen games, even without test-set gradient updates, because the selection process can overfit test noise. They also correctly predicted that trying more architectures worsens the effect and a larger test set reduces it; this clears the diagnostic prerequisite for the direct Chapter 1 path, with 50% stated confidence suggesting the idea should be retrieved again later for storage strength.
